Purpose

Not finance done to communities. Finance they drive.

Communities that self-actuate need capital that moves with their activity — sourced from within, topped up from outside, and settled on open rails they can verify for themselves.

Tech references

Open rails for community value.

The protocols and services selfdriven.finance builds on — payments native to the web, bitcoin assets bridged to Cardano, and smart contracts delivered as a managed service.

  1. 01 · Payments

    x402

    An open payment standard built on the HTTP 402 status code, so people, apps, and agents can pay for resources directly over the web.

    x402.org
  2. 02 · Bridge

    Cardinals

    Bitcoin Ordinals bridged to Cardano for the first time, using the BitVMX protocol.

    IOHK newsroom
  3. 03 · Specification

    Cardinals spec

    The open specification for how Cardinals are represented and moved between Bitcoin and Cardano.

    github · cardinal-spec
  4. 04 · Contracts

    Managed contracts

    Maestro's managed contracts API for Cardano — ready-made smart contract functionality reached through an API instead of bespoke on-chain code.

    Maestro docs
